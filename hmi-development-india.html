Operator screens built around the machine

HMI development can include overview screens, manual and automatic modes, machine status, setpoints, process values, alarm views and maintenance screens. Screen structure should make common actions easy to find and abnormal conditions easy to understand.

Alarms, trends and recipes

The listed HMI scope includes alarm handling, trend views, recipes and multi-level user access. Alarm text should describe the condition clearly; trends should show useful process history; recipe controls should support the machine's actual setup and changeover process.

Supported HMI platforms

Machcraft lists Siemens KTP, Delta DOP and Weintek HMI platforms. The appropriate device and software depend on the PLC, communication protocol, screen requirements and project budget.

PLC and HMI integration

An HMI is most useful when its tags, status indications, commands and alarms match the PLC program. The interface scope can be coordinated with PLC programming and machine commissioning so that operators see consistent machine states.
